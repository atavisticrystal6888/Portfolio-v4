## Who it's for, and why

Zerodha Kite shows a retail trader holdings, day P&L and a simple chart, and stops there. It does not say how a position looks across timeframes, how much the portfolio could lose, how it would have behaved through a crash, or where a forecast puts it with an honest error bar.

Those answers cost a Bloomberg or Refinitiv terminal; the retail alternative is a folder of fragmented Python scripts.

KiteEdge is a personal tool: a private repo, built solo, run against my own Kite account, with no public link and no user base to report. The gap: a self-hosted, privacy-first platform that delivers institutional-quality analytics without ever touching a trade.

## What I learned before building

Two strands: what a professional portfolio manager tracks daily, and a benchmark of Smallcase, Tickertape and Screener.in on technical depth, risk quantification and forecasting.

Three findings changed the plan: multi-timeframe technical analysis, not just daily; portfolio-level risk decomposition with scenario stress testing, which became a core module rather than a chart; and forecasting with confidence intervals, which set the rule that every predicted number ships with its error.

A fourth finding set a constraint: no free source covers Indian small-cap fundamentals completely.

## The bets, and what we cut

**Analytics only.** The platform never executes a trade: zero regulatory exposure, and the user never trusts it with an order. Set before the first endpoint, it shaped every integration.

**Self-hosted privacy.** Kite OAuth tokens live only in Redis with an 18-hour TTL, never on disk; no data leaves the user's machine. Trust is enforced by architecture, not policy.

**Free data sources.** No Bloomberg budget, so fundamentals are best-effort and nullable by design, and every derived number carries its methodology.

## What we built

**Connect, then watch it move.** Sign in with Kite; the dashboard updates live as ticks arrive, and alert rules send an email when a condition is met.

**What have I actually earned?** Multi-year XIRR per holding and for the portfolio, nightly dividend tracking, and breakdowns by sector, asset class and market cap.

**What is this position doing?** 43+ technical indicators across trend, momentum, volatility and volume, on timeframes from one minute to daily, composited into a Technical Summary Score from -100 to +100 with buy and sell bands.

**How much could I lose?** Sharpe, Sortino, Calmar, Treynor, beta and alpha; Value at Risk by four methods including Conditional VaR; a correlation matrix; drawdown depth, duration and recovery; and stress tests against COVID-19, the GFC, Demonetisation and the Taper Tantrum. Every figure carries its method.

<Decision>
Analytics only was the most consequential call. The platform reads a Kite account and never writes to it: no order placement, ever, in exchange for zero regulatory exposure and a trust story a self-hosted tool can keep.
</Decision>

**Where might it go?** An ARIMA/SARIMA and Prophet ensemble, with MAE, RMSE, MAPE and directional accuracy from walk-forward backtesting attached to every forecast.

**Am I any good, and are the models?** A FIFO-matched trade journal turns order history into realized P&L, win rate, profit factor and expectancy. An append-only suggestion journal records what the models recommended and how those calls aged; the user cannot edit it.

**What should I look at next?** A NIFTY 500 screener with fundamentals per symbol and tier-ranked composite scoring, refreshed nightly, and a deploy advisor that proposes allocations in whole shares.

**Take it where I already work.** QuantStats tear sheets as HTML, and OData v4 entity sets so Power BI and Excel can live-refresh.

## How we knew it worked

Forecasts report their walk-forward error, Monte Carlo VaR states its simulation count and distribution assumptions, stress tests cite the event and date range, and the suggestion journal records every model call and how it aged. 127 test files cover the Elixir apps and the Python engine.

The limits are plain: one user, no pilot, and I have not yet recorded how long I have run it or on how many positions. There is no headline accuracy figure; the walk-forward metrics live in the tool.

### Polyglot services

Elixir/OTP for real-time streaming and concurrency (Phoenix Channels, Broadway for Kafka consumers); Python for quantitative computation (pandas, NumPy, SciPy, statsmodels); React/TypeScript for visualisation. Elixir handles 100K+ concurrent WebSocket connections with minimal memory.

### Umbrella monorepo with service boundaries

Gateway (Phoenix), Market Data (OTP GenServer) and Notification (Broadway) live in an Elixir umbrella; the Analytics Engine (Python/FastAPI) and Data Pipeline (Kafka consumers plus nightly schedulers) are separate services. Docker Compose runs 13 services with health checks on every stateful one.

```
KiteEdge/
├── apps/
│   ├── kite_edge/          # Core domain - Ecto schemas, Kite API client
│   ├── kite_edge_web/      # Phoenix REST + channels - 50 endpoints
│   ├── market_data/        # KiteTicker → Kafka publisher
│   └── notification/       # Broadway Kafka consumer → alerts + email
├── analytics_engine/       # Python FastAPI - indicators, risk, forecasts
├── data_pipeline/          # Kafka consumers + nightly schedulers
│                           #   candles, indicators, alerts, forecasts,
│                           #   fundamentals, dividends, universe screener
├── dashboard/              # React SPA - interactive dashboard
└── infra/                  # Docker, Grafana, Kafka, Prometheus config
```

### Streaming path

Market Data connects to Kite's binary WebSocket (KiteTicker), decodes ticks and publishes to 8 Kafka topics. The Data Pipeline builds 1m, 5m, 15m, 1h and daily candles, computes indicators and evaluates alert rules; Notification emails alerts. Phoenix Channels push live updates to the dashboard.

### Technical analysis engine

Trend (SMA, EMA, MACD, ADX, Ichimoku, Parabolic SAR, Aroon), Momentum (RSI, Stochastic RSI, Williams %R, CCI, ROC, KAMA), Volatility (ATR, Bollinger Bands, Keltner Channel, Donchian) and Volume (OBV, VWAP, CMF, MFI, ADI).

### Risk analytics

VaR via Historical, Parametric Gaussian and Monte Carlo (10,000 GBM simulations), plus Conditional VaR / Expected Shortfall. The correlation matrix uses Ledoit-Wolf shrinkage.

```python
# Monte Carlo VaR - 10,000 GBM simulations
def monte_carlo_var(returns, portfolio_value, days=10, sims=10_000, ci=0.95):
    mu = returns.mean()
    sigma = returns.std()
    
    # Geometric Brownian Motion
    Z = np.random.standard_normal((sims, days))
    daily_returns = np.exp((mu - 0.5 * sigma**2) + sigma * Z)
    price_paths = portfolio_value * np.cumprod(daily_returns, axis=1)
    
    final_values = price_paths[:, -1]
    var_absolute = portfolio_value - np.percentile(final_values, (1 - ci) * 100)
    cvar = portfolio_value - final_values[final_values <= np.percentile(
        final_values, (1 - ci) * 100
    )].mean()
    
    return {"VaR": var_absolute, "CVaR": cvar, "simulations": sims}
```

### Forecasting

ARIMA/SARIMA auto-fitted via AIC/BIC selection; Prophet on the NSE trading calendar with weekly seasonality; combined by an inverse-MAE weighted ensemble.

### Portfolio intelligence layer (shipped May to Aug 2026)

The screener runs a 400-bar backfill plus fundamentals per symbol on a resumable nightly scheduler. Tear sheets come from QuantStats 0.0.81 (the sheet above: seeded RNG, 248 trading days, benchmark alongside). Tax estimates carry documented caveats instead of posing as advice.

### Testing and observability

127 test files across the Elixir apps and the Python analytics engine; Prometheus and Grafana for observability.
